# Colmadom Cloud

Aplicación web de punto de venta y administración para colmados. Incluye inventario, caja, ventas, pedidos digitales, facturación y funciones administrativas.

## Desarrollo

Consulta `package.json` para comandos y scripts disponibles. Configura las variables de entorno de Firebase, mSeller y demás integraciones usando un archivo `.env.local` fuera del control de versiones.
